# GitHub Pages – Carte Vianney

Dépose dans ce dossier :
- `index.html`
- `logo.png`
- `photo.jpg`
- `contact.vcf`

## Mise en ligne sur GitHub Pages
1. Crée un dépôt GitHub.
2. Envoie ces fichiers à la racine du dépôt.
3. Va dans **Settings > Pages**.
4. Dans **Build and deployment**, choisis :
   - **Source** : Deploy from a branch
   - **Branch** : `main`
   - **Folder** : `/ (root)`
5. Attends 1 à 2 minutes.
6. Ton site sera en ligne sur une URL du type :
   `https://tonpseudo.github.io/nom-du-repo/`

## Important
Les noms de fichiers doivent rester exactement :
- `logo.png`
- `photo.jpg`
- `contact.vcf`

Sinon la page ne trouvera pas les fichiers.
